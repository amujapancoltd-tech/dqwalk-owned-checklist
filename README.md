# ドラクエウォーク 所持チェック

GameWithのドラクエウォーク情報を参考にした、個人用の武器・こころ所持チェックです。

## できること

- 武器とこころを切り替えて表示
- 名前や特徴で検索
- 所持している項目に印を付ける
- 未所持だけを表示
- 所持状況をブラウザに保存
- 所持状況をバックアップ・復元
- GameWithの参考ページを開く
- GameWithから武器・こころ一覧を取得して更新

## 起動方法

作品フォルダを開いて、次の命令を実行します。

```text
..\.venv\Scripts\python.exe server.py
```

その後、ブラウザで次のページを開きます。

```text
http://127.0.0.1:8765
```

## GameWithから最新データを取得する

武器だけを更新し、武器のアイコン画像も作品フォルダ内へ保存する場合は、次の命令を実行します。こころの既存データは残ります。

```text
..\.venv\Scripts\python.exe sync_gamewith.py --weapon
```

次の命令を実行すると、GameWithの武器一覧とこころ一覧を取得し、`data.json`を更新します。

```text
..\.venv\Scripts\python.exe sync_gamewith.py
```

更新後にブラウザを再読み込みすると、最新の一覧が表示されます。ページに掲載されている更新日も保存します。既存の項目は同じIDを引き継ぐため、所持チェックを維持しやすくしています。

終了するときは、実行中の画面で `Ctrl+C` を押します。

## 大切な注意

取得した一覧は `data.json` に分けて保存します。所持チェックは外部サイトへ送られず、使っているブラウザの中だけに保存されます。

GameWithのページ構成が変更された場合は、取得できる件数が減る可能性があります。更新は必要なときに手動で実行し、短時間に繰り返し取得しないでください。

このツールは、GameWithの記事文章をそのまま使わず、数値・スキル名などの事実情報のみを独自の見出しで再構成しています。画像素材はゲーム内アイコンをそのまま使用しています。運営（スクウェア・エニックス）またはGameWithから利用停止の要請があった場合は、速やかに該当部分の公開・収益化を停止します。自動取得する場合も、利用規約・robots.txt・アクセス頻度を守ります。
